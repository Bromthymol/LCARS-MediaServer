# LCARS MediaServer

## Projektziel

Entwicklung einer eigenen LCARS-Weboberfläche für einen Medienserver auf Basis von Jellyfin.

## Design

- Modernes LCARS-Design als Standard
- Klassisches Star-Trek-TNG-Design als späteres alternatives Theme
- Responsive Bedienung auf PC, Smartphone und Fernseher

## Geplante Funktionen

- Medienbibliotheken für Filme, Serien und Musik
- Suche und Detailansichten
- Videowiedergabe über Jellyfin
- Theme-Auswahl
- Docker-basierter Betrieb auf einem privaten NAS

## Technologie

- HTML
- CSS
- JavaScript
- Git
- Jellyfin API
- Docker und Docker Compose
